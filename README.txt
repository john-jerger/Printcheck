PrintCheck - Website Package
============================

1) multi-page-site/   -> Upload this folder to your hosting (best for SEO).
   index.html, about, contact, privacy, terms, disclaimer,
   black-and-white / color / cmyk test pages, sitemap.xml, robots.txt, favicon.svg
   Open index.html to preview. Keep all files in the same folder.

2) all-in-one/printcheck-all-in-one.html -> ONE file with every page inside.
   Works anywhere (phone, preview). Navigation runs inside the file.

Before going live, replace in all files:
   https://john-jerger.github.io/Printcheck  -> your real domain
   contact@printcheck.example      -> your real email
Add an og.png image (1200x630) to the site root for social sharing.
Submit sitemap.xml in Google Search Console.
Privacy/Terms are templates: have them reviewed for your country.
