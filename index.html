What Is a Printer Test Page?

A printer test page is a short diagnostic print that shows whether your printer is working properly. It combines solid color blocks, a gray gradient, text in several sizes and alignment lines on one sheet, so a single glance tells you if ink or toner, the print head, the paper feed and the connection are all healthy.

Why Print a Test Page?

  • After setup: confirm a new printer and its driver work end to end.
  • After changing a cartridge: make sure the new ink or toner prints evenly.
  • When quality drops: find out whether the cause is hardware, ink or software before you waste paper.
  • After a long idle period: inkjet nozzles can dry out, and a test page shows it straight away.
  • Before an important print job: a 30-second check beats a ruined batch.

How to Print a Test Page, Step by Step

Using PrintCheck on any device

  1. Open the Black & White, Color or CMYK test page and look at the live preview.
  2. Select your paper size (A4, Letter, Legal or A3) and orientation.
  3. Press Print test page.

How to Read Your Test Page Results

Examine the page right after it prints, in daylight or bright light. Every block should be solid, every line straight and every letter sharp.

Inkjet vs Laser Test Pages

Inkjet printers spray liquid ink through tiny nozzles, so the most common faults are clogged nozzles and low ink, which appear as streaks or faded colors. Laser printers fuse toner onto paper with a drum and a heated fuser, so faults usually appear as gray bands, smudges or marks that repeat at regular intervals. Use the color and streak pages for inkjets and the black and white page for lasers.

Is the CMYK Test Page a True CMYK Test?

Web browsers draw in RGB, and your printer driver converts those colors to ink. That means any online test page, including this one, cannot send exact CMYK values. It is still very effective at showing a faded or blocked ink, uneven coverage and banding. For professional color proofing, use a CMYK PDF from your print shop and a calibrated workflow.

Common Printing Problems and Quick Fixes

The test page prints but documents do not

The hardware works. Restart the Print Spooler service, clear the print queue, update or reinstall the driver and try printing from a different application.

The test page prints blank

Remove the protective tape from new cartridges, reseat all cartridges, check ink levels and run a cleaning cycle.

Colors look wrong

Make sure the paper type in the print dialog matches the paper loaded, run a cleaning cycle and compare each color block to find the weak channel.

Tips for Accurate Results

  • Use the same paper size in the tool, the print dialog and the paper tray.
  • Keep scale at 100%; never choose Fit to page for a test.
  • Enable Background graphics, otherwise colored blocks may print blank.
  • Test on plain paper first to save photo paper.
  • Compare the result against your printer's own report if you still doubt the page.

Keep Your Printer Healthy

Print a short color page every week or two if the printer sits idle, which keeps inkjet nozzles moving. Use quality paper, keep the printer away from dust and heat, and power it off from its own button so the heads park correctly. When a test page looks wrong, fix the cause early instead of running many cleaning cycles, because each cycle uses ink.

Frequently asked questions

What is a printer test page?

A printer test page is a diagnostic print with color blocks, a gray gradient, text samples and alignment lines. It shows whether ink, nozzles, alignment and connection are working.

How do I print a test page on Windows 10 or 11?

Open Settings, go to Printers & scanners, choose your printer, click Printer properties and press Print Test Page. Or print this page from your browser.

How do I print a test page on a Mac?

Open System Settings, choose Printers & Scanners, select your printer, then print this page from Safari or Chrome with File, Print.

Can I print a test page from my phone?

Yes. On Android use the browser menu, Print. On iPhone use Share, Print with an AirPrint printer on the same Wi-Fi.

Can I print a test page without a computer?

Many printers can print one from the control panel or Maintenance menu. Button shortcuts differ by model, so check your manual.

Why does my printer print a test page but not documents?

Hardware is usually fine. Restart the print spooler, clear the print queue, update the driver and try another app.

Is this a true CMYK test?

No. Browsers draw in RGB and your driver converts to ink. It reliably reveals faded colors, streaks and misalignment, not exact color values.

Why are my test page colors missing?

Enable Background graphics in the print dialog and make sure color printing is selected.

How do I print an A4 or Letter test page?

Pick the paper size in the tool, load the same paper, and choose that size in the print dialog at 100% scale.
